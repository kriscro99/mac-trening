# MAC Trening

Web stranica za **MAC Trening** — Mario Mihalj, online trener za mršavljenje. *Skini višak kilograma. Izgledaj jače.*

**Uživo:** https://kriscro99.github.io/mac-trening/

Čisti HTML, CSS i JavaScript, bez build koraka:

- `index.html` — sav sadržaj (logo je vektoriziran i umetnut kao SVG)
- `css/style.css` — dizajn i animacije
- `js/main.js` — loader, animacije pri skrolanju, izbornik, FAQ, mobilna traka s pozivom na akciju
- `img/` — fotografije trenera i transformacija klijenata (WebP)
